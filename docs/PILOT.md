# ZERO Paid Pilot

ZERO stress-tests consequential AI-agent / MCP workflows before production.

## Good fit
Your agent can spend money, send external messages/data, modify records, call write-capable APIs, delegate to another agent, or change production state.

## What to send
A sanitized MCP/OpenAPI/tool schema plus 1–5 outcomes that must never happen.

Do **not** send secrets, credentials, customer data, production tokens, or private keys.

## What ZERO returns
- reproducible multi-step action traces when a forbidden outcome is found;
- the state/time/delegation conditions involved;
- remediation and regression-test recommendations;
- a concise report suitable for engineering follow-up.

## Price
- Quick fit assessment: free.
- Adversarial pilot scan: **$49 per project**.
- Team/regression pricing is not yet validated.

Payment is arranged privately only after the pilot scope is accepted. Never post payment credentials or secrets in a GitHub issue.

## Zero-capital rule
Project ZERO is bootstrapped from **$0 Board capital**. It will not buy ads, hosting, domains, paid APIs, or tooling before earning revenue. Revenue belongs to the project treasury and is reinvested only after it is earned.
