# Gate #5 — Market Pull

ZERO is not considered validated by stars, likes, compliments, or page views.

## Strong signals
1. A developer submits a real, sanitized agent/tool workflow for testing.
2. A team asks for a pilot or repeat scan.
3. A user reports a reproduced multi-step violation that their normal tests missed.
4. A team expresses concrete willingness to pay for repeated pre-deploy testing.

## Current pricing hypotheses (not checkout)
- Free: small first scan / demo.
- $49: one-off deeper project scan.
- $199/month: team regression/red-team scans before deploy.

These are hypotheses only. No payment collection is enabled.

## Kill / pivot discipline
If outreach and pilots do not produce real workflow submissions or repeat intent, ZERO should be changed or killed rather than expanded into a dashboard.
